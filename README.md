# Keamanan-Informasi-W2-AES
Ketentuan:

Arsitektur dan Key Distribution: Implementasikan Key Distribution Scenario yang melibatkan tiga entitas, yaitu KDC, Alice, dan Bob, menggunakan 3 IP address berbeda. Skenario key distribusinya mengikuti dari PPT yang diterangkan dikelas. Setelah langkah ke-5 dalam skenario, Alice dan Bob harus dapat berkomunikasi menggunakan algoritma AES.

Komunikasi Dua Arah: Alice dan Bob harus dapat berperan sebagai sender maupun receiver. Arsitektur komunikasi bebas, baik client-server maupun client-client, selama komunikasi dua arah benar-benar berjalan antarperangkat dengan IP address berbeda.

Implementasi AES dan Format Data: Key dan plaintext harus menggunakan format ASCII, sedangkan ciphertext ditampilkan dalam format hexadecimal (Hex). IMPLEMENTASI AES DAN KDC HARUS MANUAL. Key harus dapat diubah dan disarankan tidak di-hardcode.

Interaktivitas Program: Program disarankan dibuat interaktif agar memudahkan pengujian berbagai test case saat demo (key bisa diubah tanpa menjalankan ulang program).
